## 文件

- `guanyinzi.json` — 结构化主本（唯一真相）。每段含稳定 ID（`gyz-篇-段`）、正文与出处字段；正文繁体原样，每段冠「關尹子曰」。
- `pages/` — 由主本生成的静态阅读页（总览 + 九篇），可直接部署。
- `scans/guanyinzi-congshu-jicheng-1936.pdf` — 版本影印件：商务印书馆《丛书集成初编》本《关尹子》（王云五主编，民国二十五年十二月初版），卷首附《四库全书总目提要》。全书一卷，公版古籍影印。MD5：`a26579a3ba064aa90e73c290768aebd9`。

## 转录规矩

- 据纸本逐页转录，异文以纸本为准，不取他本改字。
- 只存正文：注释序号、校勘记号一律剥离。
- 不附译文。

## 真伪口径

**真伪未决、层累待考。** 《汉书·艺文志》著录九篇为铁案；唐宋间道藏在册、士人征引连续，所谓「遗失千年」并不成立；今本与《老子》同科，皆为层累之书——一本病历齐全，一本病历散佚。《四库全书总目》判其「雖出於依託……不可廢也」，正式收入子部道家类。
