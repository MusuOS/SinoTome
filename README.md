# SinoTome

把中国冷门古籍做成干净、开放、人人可取用的文本。

SinoTome 是一个开放古籍文本库：逐页据纸本转录，繁体原样，只存正文，不掺注疏。每部书一个文件夹，内含结构化主本（JSON）与阅读页导出（HTML）。

## 已收录

| 书 | 文件夹 | 状态 |
| --- | --- | --- |
| 《关尹子》（《文始真经》） | [guanyinzi/](guanyinzi/) | 全书九篇录齐，167 段 |

## 规矩

- **原样转录**：以纸本为准，异文从纸本，不取他本改字。
- **只存正文**：注释序号、校勘记号一律剥离，正文保持干净。
- **结构开放**：JSON 主本即唯一真相，页面皆为其视图；段落 ID 稳定，可直接引用。
